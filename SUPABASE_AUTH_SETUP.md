# LearnMaster hosted authentication setup

The site files provide the confirmation page and secure recovery forms. Supabase controls the email template, sender, Site URL, and redirect allow list on the hosted project. These settings must be applied in the Supabase dashboard for project `rvvifdjifnjtpfwainix`.

1. Open **Authentication → URL Configuration**. Set **Site URL** to `https://k12-learning.netlify.app/`. Add `https://k12-learning.netlify.app/auth.html` and `https://k12-learning.netlify.app/auth.html?mode=password` and `https://k12-learning.netlify.app/auth.html?mode=pin` to **Redirect URLs**. Remove the localhost URL from production settings once development no longer needs it.
2. Open **Authentication → Email Templates → Confirm signup**. Set the subject to `Welcome to LearnMaster K12 — confirm your email` and paste [supabase/email-confirmation.html](supabase/email-confirmation.html). The button uses `{{ .ConfirmationURL }}` so Supabase verifies the email before redirecting to the branded page.
3. Open **Authentication → Email Templates → Reset password**. Set the subject to `Your LearnMaster K12 secure account link` and paste [supabase/email-recovery.html](supabase/email-recovery.html).
4. Configure a verified custom SMTP sender under **Authentication → SMTP Settings** to replace the Supabase sender address. The sender should be a LearnMaster address on a domain you control. Do not use a personal Gmail password in the website or repository.
5. Test with a new account using an external email address. Confirm that the email points to `k12-learning.netlify.app/auth.html` after verification, then test password and PIN recovery from Settings.

The old localhost link was generated by hosted Supabase configuration. Deploying site files alone cannot change already-sent links or hosted email settings. Send a fresh confirmation email after the URL settings are changed.
